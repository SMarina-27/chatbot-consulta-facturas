## Descripción

Chatbot simulado que permite a un proveedor consultar el estado de pago de sus facturas (pagada, pendiente o rechazada), automatizando un proceso que antes se realizaba manualmente.

## Contenido del repositorio
- BPMN.png: diagrama BPMN del proceso (flujo "to-be")
- diccionario_datos_chatbot.xlsx: diccionario de datos que maneja el sistema
- maquina_estados_chatbot_consulta_proveedores.xlsx: máquina de estados del bot
- base_datos_simulada.xlsx: base de datos simulada que contiene las hojas de cálculo "Proveedores" y "facturas"
- Chatbot...: chatbot simulado, se ejecuta en ...
- informe.pdf: documentación fianl

## Pasos para ejecutar el chatbot

1. Descargar todos los archivos de este repositorio en una misma carpeta.
2. Hacer doble clic en chatbot....
3. Se abre en el navegador y comienza la conversación automáticamente.
4. Ingresar un CUIT y un número de factura cuando el bot lo solicite
